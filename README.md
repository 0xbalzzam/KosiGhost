# Kosi Ghost

A small endless runner in the Chrome Dino style. Kosi the ghost jumps rows of tombstones, ducks under smaller evil ghosts after 500 m, and collects coins.

## Play

Hosted build: replace this line with your GitHub Pages URL after the first deploy.

Local: open `kosi.html` in a browser.

## Controls

- Jump: Space, Arrow Up, or tap
- Duck: Arrow Down, or swipe down
- Duck in the air to fall faster
- Jump and duck cannot be used together on the ground

## Rules

- Tombstones come as 1, 2, or 3 in a row. Jump them.
- After 500 m, smaller evil ghosts appear. Duck under them.
- Coins add to the coin counter. Distance is shown in meters.
- Speed rises with distance, and gaps shrink a little.
- A hit ends the run and shows distance and coins.
- Share on X opens a post with the score and a link to this page. On phones that support Web Share, the canvas screenshot is attached. Otherwise use Screenshot and add the image yourself.
